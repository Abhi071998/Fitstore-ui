# FITstore UI

A storefront landing page for FITstore, built with React, Vite, and Redux Toolkit.
Includes a login/register flow wired to a backend auth API.

## Clone

```bash
git clone https://github.com/Abhi071998/Fitstore-ui.git
cd Fitstore-ui
```

## Installation

```bash
npm install
```

## Environment variables

Copy `.env.example` to `.env` and set your backend URL:

```bash
cp .env.example .env
```

## Running

```bash
npm run dev      # start the dev server
npm run build     # production build
```
